Colab MCP for Claude

MirageLog3 が個人で使うための OAuth アプリです。Claude から Google Colab の公式 MCP サーバー（colaboratory.googleapis.com）に接続するためだけに使います。

This is a personal OAuth app used by MirageLog3 to connect Claude to the official Google Colab MCP server. It is not offered to the public.
