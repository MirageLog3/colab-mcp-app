プライバシーポリシー / Privacy Policy

最終更新 / Last updated: 2026-11-25

「Colab MCP for Claude」（以下、本アプリ）は、運営者 MirageLog3 が個人で使うための OAuth クライアントです。

  • 本アプリは、Google アカウントの認可を Claude（claude.ai）に渡し、Google Colab の API（colaboratory.googleapis.com）を呼び出すためだけに使います。
  • 運営者が独自にユーザーデータを集めたり、保存したり、第三者に共有したりすることはありません。
  • アクセストークンは Claude 側と Google 側で管理されます。各サービスでのデータの扱いは、それぞれのプライバシーポリシーに従います。
  • Google API から受け取った情報の利用は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。
  • 認可はいつでも Google アカウントの「サードパーティ製のアプリとサービス」から取り消せます。

This app is a personal OAuth client used only by its operator to let Claude call the Google Colab API. The operator does not collect, store, or share any user data. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from your Google Account settings.
